# Glass Furnace Energy Optimizer 🧪🔥

Applicazione per il monitoraggio e la previsione dell'apporto energetico nei forni fusori per vetro.

Il sistema raccoglie le misurazioni operative di conduzione e utilizza un algoritmo di **Machine Learning (Random Forest)** per stimare il fabbisogno ottimale di gas e supporto elettrico (elettrodi) in base al tiraggio (cavato) e alle temperature di esercizio.
